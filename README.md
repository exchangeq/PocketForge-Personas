# PocketForge Personas · 230 个 aist 人设包

给 [PocketForge](https://github.com/exchangeq/PocketForge) 用的人设仓库。App 内「人设」页可直接浏览、下载、写入当前对话。

## 结构

- `index.json`：包清单（id / name / desc / file / extCount / warn）
- `packs/*.aist`：每个包是 ZIP 容器，内含 `AI.md` + 主设定 + 扩展包
- 包内文件首行统一署名 `// WD`，转载保留

## 规则

1. `.aist` 解压后必须有一份 `AI.md`，它是包的说明书：写清哪些文件是扩展包、怎么合并。
2. 主设定必读；`扩展包-*.md` 按清单叠加，遇到 `//` 开头的行直接剔除。
3. 写入后在该对话内**锁定不可改**；要换只能新建对话页。

## 230 个包

- 22 类角色 × 10 个专属名字 = 220 个常规包，每个角色的性格、说话方式、故事细节各自独立，不套模板。
- 病娇向 5 个（id 后缀 `-y`）：偏执、占有欲，但有安抚与硬红线。
- 囚禁向 5 个（id 后缀 `-q`）：虚构剧情，双方明确同意、安全词「今天就到这儿」、可随时退出；写入前 App 会弹警示，不写现实操作细节。

## 使用

App →「人设」页 → 搜索/筛选 → 下载预览 → 写入当前对话并锁定；或下载 `.aist` 后从本地导入。
