# PocketForge Personas · 530 个 aist 人设包

给 PersonaChat / PocketForge 用的人设仓库。App 内可直接浏览、下载、写入当前对话。

## 结构

- `index.json`：包清单（id / name / desc / file / extCount / warn）
- `packs/*.aist`：ZIP 容器，内含 `AI.md` + 主设定 + 扩展包
- 每个文件首行 `// WD`，转载保留署名

## 530 个包

- 52 类角色（猫娘、狐娘、护士、调酒师、钟表匠、极地研究员…）× 10 个专属名字 = 520 个常规包。
- 病娇向 5 个（`-y`），囚禁向 5 个（`-q`，虚构、双方明确同意、安全词、可随时退出、写入有警示）。
- 每个包性格不同，含「七、只属于你们的细节」独占段落；名字全局唯一。

## 使用

App → 首页搜索/下载 → 写入当前对话；或下载 `.aist` 本地导入。也支持 SillyTavern PNG 角色卡与 JSON 角色卡导入（PersonaChat）。
