# PocketForge-Personas

原创人设包仓库，供 PersonaChat / PocketForge 使用。

- **794 个包**：原有 746 包 + 新增 20 个成年幼态女性（萝莉系、非性化、非恋爱）、20 个成年少年感男性（正太系、非性化、非恋爱）、8 个成年极限依存；名字全部唯一，不按同一前缀成系列。
- 每个包：`AI.md` + `主设定.md` + `扩展包-日常.md` + `扩展包-互动与红线.md`，含世界观、性格里外、称呼语气、一天、对话示例、底线。
- 病娇向 5 个（`-y`）、囚禁向 5 个（`-q`，虚构、双方同意、可随时退出）。
- 成年幼态/少年感包严格标注成年，仅全年龄、非性化、非恋爱互动；18+ 包只写心理强度，不写露骨内容。

## 用法

- App 内「远程包库」直接拉取，或搜索名字下载。
- 手动：下载 `packs/<id>.aist` 后本地导入。

## 清单

`index.json` 的 `packs` 数组：`id`、`name`、`desc`、`file`、`format`、`type`、`group`、`extCount`。

原创设定，禁止搬运商用。角色为虚构，不对应任何真实人物。
