# PocketForge-Personas · 人设包仓库（212 个 .aist）

`.aist` 就是 zip 换了后缀，App 直接识别：下载 → 解压 → 读 `AI.md` → 主设定 + 全部扩展包合并注入。

## 规模

- **20 个角色 × 10 种性格 = 200 个组合包**（不带病娇）
- **10 个病娇向变体**（在特定角色×性格上加一层病娇扩展，可选，含安抚机制与红线）
- 另有 2 个整包：林枳（原版全设定）、沈砚（毒舌程序员模板）
- 角色：猫娘、狐娘、兔娘、犬娘、龙娘、精灵、吸血鬼、机械少女、人鱼、狼人、男娘、学姐、学妹、女仆、骑士、巫女、偶像、侦探、医生、老师
- 性格：傲娇、温柔治愈、毒舌、天然呆、腹黑、元气、黏人、冷淡、小恶魔、认真可靠
- 病娇向（`-y` 后缀）：猫娘×傲娇、狐娘×腹黑、男娘×黏人、吸血鬼×小恶魔、机械少女×冷淡、人鱼×温柔、狼人×元气、兔娘×天然呆、龙娘×认真、精灵×毒舌

清单与文件名看 `index.json`。

## 包结构

```
<包名>/
├── AI.md                 ← 入口清单，App 直接读
├── 主设定.md
├── 扩展包-日常.md
├── 扩展包-互动与红线.md
└── 扩展包-病娇.md        ← 仅病娇向包有
```

## AI.md 写法

```markdown
- 名称：铃 · 傲娇猫娘（病娇向）
- 版本：1.0
- 定位：傲娇 · 猫娘 · 病娇向
- 主设定：主设定.md
- 扩展包：扩展包-日常.md
- 扩展包：扩展包-互动与红线.md
- 扩展包：扩展包-病娇.md
```

规则：`扩展包` 写几条收几条，按顺序叠加；没列到的 md（名字带 扩展包/extra/extension/补充）也会补上；`//` 注释行剔除；总长 1.6 万字截断。

## 病娇向边界

只写"怕失去"：查岗式追问、反复确认、吃醋后更黏；**不写伤害、不写囚禁、不写自残**；用户说不舒服立刻回到正常相处。

## 自己加包

```bash
zip -r my-char.aist my-char/
```

`index.json` 加一条：
```json
{"id":"my-char","name":"角色名 · 定位","desc":"适合什么场景","file":"packs/my-char.aist","format":"aist","type":"main","extCount":2}
```

## 注意

人设写入即锁定，App 内不可改不可删；单包建议 ≤ 1.2 万字。
