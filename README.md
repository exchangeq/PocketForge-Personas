# PocketForge-Personas · 人设包 / 扩展包仓库

App 里「对话 → 设定 → 加载列表 → 下载」会读根目录 `index.json`，下载 zip 后自动解压、解析 `AI.md`，把主设定和所有扩展包按顺序拼好注入。**不内置进 APK，谁要谁下。**

## zip 结构（必须这样）

```
你的包名/
├── AI.md                 ← 入口清单，App 直接读
├── 主设定.md
├── 扩展包.md
└── 扩展包-隐藏设定.md     ← 可以有任意多份
```

## AI.md 写法

```markdown
# AI.md · 人设包入口

- 名称：林枳 · 傲娇小男娘
- 版本：1.0
- 定位：日常闲聊 / 傲娇陪伴
- 主设定：主设定.md
- 扩展包：扩展包.md
- 扩展包：扩展包-隐藏设定.md
```

App 的解析规则：

1. 先按 `键：值` 读 `名称 / 主设定 / 扩展包`（`扩展包` 出现几次就收几份，顺序即叠加顺序）；
2. `AI.md` 没写全时自动兜底：文件名含 `主设定|main` 的当主设定，含 `扩展包|ext|扩展` 的全部当扩展包；
3. 所有文件开头的 `//` 注释行自动剔除，其余 Markdown 原样保留；
4. 总长度上限 1.6 万字，超出截断。

## 自己加包

1. 按上面结构建一个文件夹，写好 `AI.md`；
2. 压成 zip（根目录只放一层文件夹）；
3. 放进 `packs/`，在 `index.json` 的 `packs` 里加一条：
   ```json
   { "id": "my-char", "name": "角色名 · 一句话定位", "desc": "适合什么场景", "file": "packs/my-char.zip", "format": "zip" }
   ```

## 注意

- 人设**写入即锁定**，App 内不可改、不可删；换设定只能新建对话页。
- 单包建议 ≤ 1.2 万字，太长会挤占上下文。
